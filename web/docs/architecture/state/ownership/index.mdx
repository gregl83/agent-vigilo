# State Ownership

Which process owns each state transition and which database guard prevents conflicting writers.

<Mermaid value={ownershipDiagram} />

## Notes

- CLI commands create, cancel, and read state.
- Coordinators own expired chunk lease recovery, run dispatch, run finalization, and outbox publishing.
- Workers own chunk leases, execution attempt allocation, retry scheduling, and execution/attempt terminal transitions. Chunk-local worker state is addressed by `run_id + run_shard + chunk_id`.
- DB guards are the authority boundary: shared run-state locks, leases, conflict keys, current-attempt checks, and outbox delivery claim tokens prevent stale writes.
