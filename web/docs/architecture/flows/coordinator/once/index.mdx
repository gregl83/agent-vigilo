# Coordinator Once Command

How `vigilo coordinator once` executes one configurable bounded orchestration
cycle and exits. It first resumes expired `creating` runs, then performs chunk
lease recovery, dispatch, finalization, and outbox publication. Dispatch work is
claimed by `run_id + run_shard` cursor so each chunk-ready window is
partition-local.
